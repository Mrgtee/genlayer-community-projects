# Contributing: Add Your Project

To add your project to the GenLayer Community Projects page:

## Steps

1. Fork this repository
2. Open `data/community-projects.ts`
3. Add your project in this format:

```ts
{
  name: "",
  slug: "",
  logo: "/project-logos/yourlogo.svg",
  description: "",
  website: "",
  domainLabel: ""
}

4. Add your logo inside /public/project-logos/
5. Submit a Pull Request
